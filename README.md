# Employee Management System

## 📌 Project Description

This is a database-driven Employee Management System built using Python and Tkinter for the graphical user interface.
The application allows users to manage employee records efficiently with operations like adding, removing, promoting, and displaying employees.

---

## 🚀 Features

* ➕ Add Employee
* ❌ Remove Employee
* ⬆️ Promote Employee (Update Salary)
* 📋 Display All Employees

---

## 🛠️ Tech Stack

* Python
* Tkinter (GUI)
* SQLite (Database)

---

## 📂 Project Structure

```
Employee-Management-System/
│
├── main.py
├── database.db
├── requirements.txt
└── README.md
```

---

## ⚙️ How It Works

1. User enters data in the GUI
2. Button click triggers Python function
3. Function executes SQL queries using SQLite
4. Database is updated
5. Data is stored locally in `database.db`

---

## ▶️ How to Run the Project

1. Clone the repository:

```
git clone https://github.com/your-username/Employee-Management-System.git
```

2. Navigate to the project folder:

```
cd Employee-Management-System
```

3. Run the application:

```
python main.py
```

---

## 📦 Requirements

```
tkinter
sqlite3
```

*(Note: sqlite3 comes pre-installed with Python)*

---

## 💡 Advantages of SQLite

* No server setup required
* Lightweight and fast
* Database stored as a file (`.db`)
* Easy to share and run on any system
